# Чеклист: ежедневная уборка офиса

Практический список для офис-менеджера или клинера. Подходит для open space, кабинетов и переговорных.

Источник: [GreenCleaning](https://greencleaning.by/) · услуга [уборка офисов](https://greencleaning.by/uslugi/dlya-biznesa/uborka-ofisov/)

## Общие зоны

- [ ] Входная группа: коврик, пол, ручки дверей
- [ ] Ресепшен / стойка: поверхности без разводов, мусор
- [ ] Коридоры и холлы: пыль на плинтусах, сухая/влажная уборка пола
- [ ] Лифтовые холлы (если есть): пол, зеркала, кнопки
- [ ] Кухня / кофе-пойнт: столешницы, мойка, техника снаружи, пол
- [ ] Санузлы: сантехника, зеркала, расходники (бумага, мыло), пол
- [ ] Мусорные корзины: опустошить, при необходимости заменить пакеты

## Рабочие места

- [ ] Столы: влажная протирка доступных поверхностей (без бумаг сотрудника)
- [ ] Оргтехника снаружи: мониторы, клавиатуры — сухая/антистатик по регламенту
- [ ] Стулья и ножки столов: видимая пыль
- [ ] Подоконники и открытые полки

## Переговорные

- [ ] Стол переговоров и оргтехника
- [ ] Стулья / кресла
- [ ] Маркерная доска / стекло (по необходимости)
- [ ] Пол и мусор

## Финал смены

- [ ] Проверить расходники на завтра
- [ ] Закрыть окна (по регламенту объекта)
- [ ] Выключить лишний свет в зонах уборки
- [ ] Короткий отчёт офис-менеджеру (если предусмотрено договором)
